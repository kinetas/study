# 7월 28일 필기 — PySpark 학습 환경 구축 (싱글 노드 / 멀티 노드 클러스터)

## 핵심요약

오늘은 PySpark 학습 환경을 두 가지 방식으로 구축하고 기초를 익혔다. **00**에서는 Jupyter 컨테이너 하나에서 `SparkSession`/`SparkContext`로 RDD·DataFrame 기본기(워드카운트, 필터링, Spark SQL)를 실습했고, **01**에서는 실제 Spark 마스터-워커 클러스터에 연결해 분산 처리(`rollup` 집계)를 실습했다.

---

## 00 — 싱글 노드 환경 (`00/`)

- 환경: Jupyter 컨테이너 1개(`jupyter-ml`), `master("local")` 모드
- 포트: `9999 → 8888`
- 볼륨: `./실습코드` → `/home/jovyan/work`

### `01.ipynb`
`SparkSession` 생성부터 시작: 로컬 CSV(착한가격업소 데이터) 로드 → 스키마/행 수 확인 → `업종 == 양식` 필터링 → 결과를 CSV로 저장.

### `02.ipynb`
`SparkContext`를 이용한 로우레벨 RDD 실습: `textFile`/`parallelize` → `flatMap`/`map`/`reduceByKey`로 워드카운트 구현 (MapReduce 개념 정리 포함).

### `03.ipynb`
`SparkSession.master("local[*]")`로 전체 코어 활용. RDD 워드카운트 + DataFrame 생성/필터링 + `createOrReplaceTempView`로 Spark SQL 조회 실습. 셔플링(Shuffling)과 캐싱(`.cache()`) 개념 정리.

### `func.ipynb`
Transformation vs Action API 정리:
- Transformation: `map`/`filter`/`union`/`distinct` 등
- Action: `collect`/`count`/`reduce`/`take` 등
- RDD 생성 방법(`parallelize`/`range`/`textFile`), Lazy Evaluation, RDD Lineage 설명

## 01 — 멀티 노드 클러스터 환경 (`01/`)

- 환경: `jupyter-ml`(Spark 마스터 겸 Jupyter) + `spark-worker-1`, `spark-worker-2`(각 2g 메모리 제한)
- 포트: `9999`(Jupyter), `4040`(Spark Job UI), `8080`(Spark 마스터 관리자 UI)
- 워커 컨테이너도 동일한 `./실습코드` 볼륨을 마운트해서 마스터와 같은 노트북을 바라봄

### `01.ipynb`
`spark://jupyter:7077` 클러스터 마스터에 연결해 워커 분산 처리 실습:
1. 착한가격업소 CSV 로드 (스키마/행 수/미리보기 확인)
2. `inferSchema` 끄고 `repartition(4)`로 파티션 강제 분할
3. 가격 컬럼을 정수로 변환
4. `rollup("업종", "시도")`로 업종별 / 업종+시도별 평균 가격 집계
